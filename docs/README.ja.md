# Proteus

Proteusは、オーバーレイテクスチャをキャラクターの肌や装備にゲーム実行中に合成する、FFXIV向けのDalamudプラグインです。MOD作者はPenumbra MODに小さなPNGオーバーレイを添えて配布し、Proteusはオプションを変更するたびにそれをベーステクスチャへ合成します。元のMODファイルには一切手を加えません。ProteusはProteus対応のpmpファイル、Onionのオーバーレイompファイル、Atramentum Luminisのグロータトゥーを取り込めます。さらに、Proteus製かどうかを問わず、インストール済みのあらゆるMODのモデルを編集できます。服の形を整える、風の揺れを塗る、パーツにスイッチを付ける、髪を帽子の下に収める、といったことが可能です。

オーバーレイの描画方法は2通りあります。肌に直接描き込むか、**セカンドスキン** — 装備として描画されるボディメッシュのコピー — として描くかです。後者なら、肌マテリアルでは扱えないスフィアマップ、メタルネス、アニメーショングローをオーバーレイで使えます。

- **装備枠を犠牲にせずにMODを着られます。** セカンドスキンはアイテムとして描画するしかありませんが、Proteusは使っていないもの — 透明なメガネ、着けていない指輪、あるいは装備中のアクセサリへの追加 — にそれを隠します。つまり実際のグラマーには影響しません。設定は不要で、ホストは自動で選ばれ、着用中のアイテムが奪われることはありません。
- **あらゆるMODの服を、キャラクターの上で直接作り直せます。** **スタジオ**タブで着用中の服を塗ると、肌が突き抜けている箇所で服を体から引き離したり、押し込んだり、なめらかにしたり、しわの上に張り渡したり、風が揺らす場所を塗ったりできます。編集はすべてMODに保存され、元に戻せます。
- **服を自分の体に合わせ直せます。** **スタジオ**は、あるボディサイズ向けに作られた服を別のサイズへ、あるいはNeolitheからRueへ、TBSEからTBSE-Xへといった別のボディMODへ移し、MODの新しいオプションとして保存できます。ゲーム本来の装備にも使え、MOD全体に他のボディの全サイズを一度に追加することもできます。
- **装備を着た瞬間に自分の体に合わせ直せます。** Penumbraのコレクションごとに一度ボディを選んでおけば、胴・脚・手・足の装備は身に着けた時点でそのボディに合わせ直されます。
- **Proteus製に限らず、あらゆるMODのあらゆるパーツにトグルを追加できます。** MODがリボンや首輪、ストラップを、作者がオプション化しなかった形でジオメトリに溶接している場合でも、**スタジオ**タブならそのパーツを切り出して本物のスイッチを付けられます。
- **Modの髪を帽子の下に収められます。** Proteusは帽子で隠れる部分の髪を頭に沿って押し付けるので、帽子が髪を突き抜けなくなります。 既定でオンで、帽子を被っている間だけ働きます。


困ったときは、まず[トラブルシューティングガイド](../TROUBLESHOOTING.md)をご覧ください。
その上で https://discord.gg/solona に参加し、#help チャンネルで質問してください。まだ新しいプラグインですが、不具合はできる限り早く直します！

作者としてProteus向けのMODを作りたい方は、[作者向けガイド](../For%20Creators.md)をお読みください。

## ユーザー向け

### インストール

/xlplugins の実験的機能タブに、このリポジトリ https://dl.solona.info/repo.json を追加してください。
保存したら、/xlplugins のメイン画面でProteusを探します。

> すでに `raw.githubusercontent.com/solona-m/plugins/main/repo.json` から導入済みですか？ そちらも
> 今後ずっと動作しますが、新しいURLの方が安定していて、GitHubの制限を受けません。

Proteus向けに作られたオーバーレイMODをいくつか入れ、オプションを選べば、キャラクターが更新されます。

### チャットコマンド

| コマンド | 内容 |
|---------|-------------|
| `/proteus` | ステータスウィンドウを開閉します。 |
| `/proteus config` | ステータスウィンドウを設定タブで開きます。 |
| `/proteus refresh` | **更新**ボタンと同じく、すぐに再合成します。マクロに便利です。 |
| `/proteus refresh full` | **更新**をShiftクリックしたときと同じく、すべてを作り直してから再合成します。通常の更新より時間がかかります。 |
| `/proteus refresh silent` | 上の2つのどちらかを、チャットメッセージなしで行います。`full` と `silent` は組み合わせられます。 |

### ステータスウィンドウ

`/proteus` でステータスウィンドウを開きます。タブは7つあり、直近の合成結果（パッチしたテクスチャ、使用したMOD、何分前か）は常に下部に表示されます。

アップデート後には、変更点を示す**Proteus の新機能**ウィンドウが一度だけ開きます。次に新しい内容があるまで、再び開くことはありません。

#### MOD

Proteusのサイドカーを含むPenumbra MODをすべて一覧表示します。列見出しをクリックすると、その列で並べ替えられます。 MOD名にカーソルを合わせると、作者が同梱した画像を確認できます。

| 列 | 内容 |
|--------|-------------|
| 有効 | そのMODに対するProteusの合成を有効/無効にします。 |
| MOD | MODの表示名。クリックするとPenumbraの該当MODへ移動します。 |
| 優先度 | Proteusの合成スタック内での優先度。数値が小さいほど先（下のレイヤー）になります。ドラッグで変更、Ctrlクリックで直接入力できます。 |
| プリセット | この Mod が今着ている保存済みの見た目。別のものを選べばカラーエディタを開かずに切り替えられます。プリセットのない Mod では — と表示されます。 |
| カラー | そのMODのカラーエディターを開きます。ストラップ端の接触影とくぼみであるSkindentは、その中の**エフェクト**で設定します。 |

**更新**をクリックすると手動で再合成でき、Shiftクリックするとすべてを作り直してから再合成します。Penumbraのオプションやモッド設定の変更、装備の変更、種族/ボディの変更があったときにも、Proteusは自動で再合成します。

#### スタジオ

Proteus製に限らず、インストール済みの**あらゆる**MODのモデルを編集します。インポートしたパックの服も対象です。体が突き抜けないように服の形を整えたり、服の一部を動かしたり大きさを変えたり、別のボディに合わせ直したり、風が揺らす場所を塗ったり、パーツを切り出して専用のオン/オフスイッチの後ろに置いたりできます。変更はすべてMOD自身のファイルに書き込まれるため、**Proteusをオフにしても動き続け**、MODを書き出せば一緒に付いていきます。

MODを選び、そのモデルを1つ選びます。タブは着用中の胴装備（なければ脚装備）を開いた状態で始まり、着用中のMODとモデルは緑色で一覧の先頭に表示されます。キャラクター上の服をクリックすると、バニラでもMODでも、そのMODとモデルが開きます。 タブ内のどの一覧も検索できます。名前の一部を入力すると絞り込まれます。種族ごとに別のモデルを同梱しているアイテムでは、見分けられるよう各モデルに種族名が付きます。

左側にツール、その隣に選んだツールの設定が並び、設定の上部にはモデルのパーツのドロップダウンがあります。**モデル表示**にチェックを入れると、右側にモデルを表示する3列目が加わります。

着用中の**バニラ装備**も *（バニラ）* の印付きで一覧に出ます。ゲーム本来の装備には編集できるMODファイルがないため、開くと新しいMODにコピーされます。コピーは変更するまで元とまったく同じ見た目です。どのツールもそのコピーに対して使えます。**体型サイズ**を選んでいるときは、バニラ装備は合わせ直す対象として開きます。[体型サイズ](#体型サイズ)を参照してください。

ツール:

| ツール | 内容 |
|------|-------------|
| パーツの切り替え | モデルのパーツを選び、オン/オフのスイッチを付けます。下の[パーツのスイッチ](#パーツのスイッチ)を参照してください。 |
| 外に引く | 表面を外側に押し出し、服から突き出た体をまた覆い隠します。布はその下の肌からまっすぐ離れる方向に動きます。 |
| 内に押す | 同じブラシの逆方向。体から離れすぎている服に使います。 |
| ならす | 表面をなめらかにします。服にもともとある凸凹や、でこぼこになった引き出しに使います。3ds Maxのリラックスと同じく縮むため、曲面は平らになり、布は体の方へ沈むことがあります。 |
| スムーズ | 縮ませる**ことなく**、凸凹や波打ちを伸ばします。ならすと違って曲面は形を保ち、布は体から離れたままです。**強さ**で効く速さを決めます。 |
| つかむ | 布を押さえてドラッグします。ブラシの周りの布がゴムのようにマウスに付いてきます。中心が最も強く、硬い境目はありません。ブラシの大きさで付いてくる布の範囲が決まり、Ctrl+Zでつかんだ操作を取り消せます。 |
| 橋渡し | お尻の割れ目やしわのようなくぼみを横切るように塗ると、布が体に沿って沈み込まず、まっすぐ張り渡されます。持ち上げる方向にしか動きません。 |
| 風 | ゲームの風がその服をどれだけ揺らすかを塗ります。赤で表示されます。消去するにはCtrlを押しながら塗るか、**量**を0%にします。 |
| 移動 | パーツ、または少数のポリゴンを矢印でドラッグします。矢印はその軸に沿って、四角はその平面上で動かします。下の[移動・回転・拡大縮小](#移動回転拡大縮小)を参照。 |
| 回転 | パーツを中心のまわりに回します。色の付いたリングをドラッグするとその軸のまわりに、外側のリングをドラッグすると視点のまわりに回ります。 |
| 拡大縮小 | パーツを中心のまわりに拡大・縮小します。押したまま右へドラッグすると大きく、左へドラッグすると小さくなります。 |
| 体型サイズ | 服を別のボディサイズ、または別のボディMODに合わせ直します。下の[体型サイズ](#体型サイズ)を参照。 |

##### ブラシの使い方

- **キャラクターに直接塗ります。** 服ではストロークが塗ったそばから表示されます。**Alt**を押しながらでカメラを動かせます。代わりにウィンドウ内のモデルに塗りたい場合は**モデル表示**にチェックを入れてください。背景からドラッグで回転、Shift+ドラッグで移動、スクロールで拡大縮小します。
- **ブラシの大きさ**は1 mmまで小さくできます。`[` と `]` で変更でき、Shiftを押すと細かく変わります。効きは中心が最も強く、端でゼロになります。ブラシの届く範囲は布の上に虹色で描かれるので目で確認できます。ブラシはフレームレートに関係なく同じ速さで働きます。**外に引く**と**内に押す**では、**強さ**は押し続けた0.25秒ごとにブラシの中心が表面を動かす距離です。それ以外のブラシでは効く速さです。通常は小さめが適切です。服は体からわずか数分の一ミリ離れれば十分で、同じ場所を何度でも重ねて塗れます。
- **上限**は、ブラシがどの点でも作者が置いた位置から動かせる最大の距離です。上限に達すると塗っても動かなくなるため、ブラシを押し続けても服が膨れ上がることはありません。大きく変えたいときは上げてください。
- **左右対称**で両側を同時に塗れます。
- **肌は動きません。** それ以外のものをブラシから守るにはロックします。キャラクターやモデル上のパーツをShift+クリックするか、パーツのドロップダウンでチェックを外してください。ロックしたパーツはモデル上でもキャラクター上でも非表示になり、クリックはその下にあるものへ通ります — スカートをロックすれば、その下の下着に手が届きます。ロックしたパーツに溶接された継ぎ目も固定されます。
- **髪にも使えます。** 髪、顔、耳、尻尾は、塗っている最中にストロークを表示するのではなく、離したときに再描画されます。
- **他のサイズにも適用**は、その編集を同じ服のMOD内の他のファイルへ、服の上での位置で対応させてコピーします。

##### 保存と取り消し

- 各ストロークは、離してから少し後にMODへ保存されます。最初の保存時に、元のモデルがMOD内の `Proteus/meshvolume-backup/` にコピーされます。
- **一筆分戻す**（またはCtrl+Z）で最後のストロークを取り消します。**やり直す**でこのモデルのストロークをすべて破棄します。
- **保存内容を元に戻す**（CtrlまたはShiftを押しながらクリック）で、このMODでブラシが変更したすべてのモデルを、作者が作ったときの状態に正確に戻します。
- パーツのスイッチ、帽子対応、ブラシはそれぞれ独自のバックアップを持ちます。複数の機能が同じモデルを変更している場合は、最も新しいものから元に戻してください。別の順番で戻そうとするとProteusが知らせます。
- モデルの体型スライダーが編集に追従できない場合があります。一緒に動かせなかった点があると、Proteusはその数を表示します。そのスライダーを有効にすると、一部で貫通が戻ることがあります。
- Modのメッシュの多くには風チャンネルがありません。最初に保存される風のストロークでチャンネルが追加され、風で動くように服のマテリアルが設定されます。MODではなくゲーム由来のマテリアルは設定できません。
- **同期プラグインを使うフレンドにも編集が見えます。** ストロークが落ち着いて保存されると、PlayerSyncやLightlessなどの同期プラグインでペアになっている相手は、スタジオを開いたままでも数秒以内に編集後の服を受け取ります。描いている途中のストロークは共有されません。パーツをロックしている場合、服全体を共有できるよう作業を止めて数秒後に再び表示されます。カーソルを合わせるか塗ると、また非表示になります。

##### 移動・回転・拡大縮小

**移動**、**回転**、**拡大縮小**は塗るのではなく、服の選んだパーツを操作します。キャラクター上かモデルビューでパーツをクリックするか、パーツ一覧から選び、その中心に出るハンドルをドラッグします。キャラクター上で作業しながらカメラを動かすには**Alt**を押してください。手を離すたびに保存され、**移動を元に戻す**で直前の操作を取り消せます。

- **パーツ単位かポリゴン単位か。** 既定ではパーツ全体を動かします。**ポリゴン**に切り替えると、少数のポリゴンだけを操作できます。クリックで選択、Shift+クリックで追加・解除、**広げる**／**狭める**で選択範囲を一周ずつ増減します。一覧でパーツを選ぶとそのパーツのポリゴンがすべて選択され、**クリア**で選択が空になります。
- **隣接パーツも動かす**をオンにすると、動かした場所の周りの布が追従し、遠いほど追従が弱まるので、服は裂けずに曲がります。**減衰**でその届く範囲を決めます。ポリゴン単位では減衰を面に沿って測るため、選択範囲とつながった布だけが追従します。近くにあるだけの別パーツは動きません。**隣接パーツも動かす**をオフにすると選択範囲だけが動きますが、隣と完全に共有している頂点は縫い目が開かないよう一緒に動きます。
- **肌とロックされたパーツは決して動きません。** ブラシの項目でパーツのロックを解除すると動かせます。
- 動かしたパーツも元々作られたボーンに従い続けるため、ボーンから大きく離すとポーズで不自然に曲がることがあります。

##### 体型サイズ

**体型サイズ**は、あるボディ向けに作られた服を別のボディに合わせ直します。同じボディMODの別サイズ（Neolithe XSからLへ）でも、まったく別のボディMOD（NeolitheからRueへ、TBSEからTBSE-Xへ）でもかまいません。

**両方のボディMODがPenumbraにインストールされている必要があります**。服が作られた側と、合わせ直す先の側の両方です。オンになっている必要はありません。Proteusは両ボディのモデルファイルを比べて服の各頂点をどれだけ動かすかを測るため、どちらもディスク上に必要です。服が作られたサイズも、そのMODのオプションのひとつである必要があります。

1. スタジオで服のモデルを開き、**体型サイズ**を選びます。初回はいくつかのヒントが表示されます。ヒントの内容が変わると再び表示されます。
2. **作成元の体型**で、服が作られたボディMODを選び、続けてそのサイズを選びます。サイズはProteusが推測し、その確からしさも表示します。
3. **リフィット先**で、目的のボディMODとサイズを1つ以上選びます。初期値は着用中のボディです。複数のサイズにチェックを入れると、一度ですべて作れます。
4. **リフィットしてプレビュー**を押してキャラクター上で結果を確認します。よければ**新しいオプションとして保存**（または**N サイズを新しいオプションとして保存**）を押します。保存するまで何も残りません。
5. **保存先**で保存する場所を選びます。**この Mod**は服自身のMODに追加し、既定では作者のサイズがすでに入っているグループに入ります（**保存先グループ**で変更できます）が、作者が次にMODを更新すると消えてしまいます。**新しいMod**は独立したMODに保存するので、更新後も残ります。どちらの場合も、Proteusをオフにしても動き続けます。

Proteusが作るMOD（合わせ直し用と、編集したバニラ装備用）は、Penumbraのモッド一覧で**Proteus アップスケール**フォルダーにまとめられます。

知っておくとよいこと:

- **新しい体型の肌を使う**は既定でオンです。サイズを変更する体の各部位について、服が持つ肌を新しいボディのものに差し替え、体の残りと揃えます。チェックを外すと、代わりに服に付属する肌のサイズを変更し、作者による寄せ上げやSkindentの形を保ちます。
- **隠れた肌を除去**は既定でオンで、作者が自分の肌を削除した場所（たいていは布の下）には新しい肌を入れません。合わせ直しで穴が開く場合はオフにしてください。**新しい体型の肌を使う**がオンのときだけ働きます。
- **体から布を押し出す**は、合わせ直しで埋もれた布だけでなく、埋もれた布をすべて押し出します。独自の脚の肌を持つストッキングなど、体が透けて見える場合に使ってください。作者は意図して布を肌の下に隠すことが多いため、既定はオフです。
- **形を保つ**は、硬いパーツ（指輪、バックル、チェーン）を曲げずにそのまま動かします。小さな閉じたパーツには最初からチェックが入っています。
- **靴と手袋は元の足と手を残します。** **元の足を残す**（または**手**）にチェックが入っている状態（既定）では、足はヒールも含めて作者が作ったままで、靴が届いている脚だけを脚のサイズに合わせてリフィットします（手袋は腕を胸のサイズに合わせて）。足は自動で付いてきます。脚に届かない靴は形をそのままに肌だけを描き直し、「*ボディ* — skin」として保存します。チェックを外すと、これまでどおり靴全体をリフィットします。
- 脚にかかるロングドレスのように**複数の部位にまたがるパーツ**は、**その他の部位（任意）**で部位ごとにサイズを選びます。部位を除外するには**なし（このパーツを含めない）**を選んでください。
- パーツ一覧で**パーツのチェックを外す**と、作者が置いたそのままの位置に残ります。
- 男性専用のものなど、**ゲームがあなたの種族向けに用意していない装備**も合わせ直せます。Proteusはまず存在するモデルからあなたの種族用のモデルを作ります。
- **バニラ装備**も同じ方法で合わせ直せます。保存先のMODがないため、保存すると合わせ直した結果と**Original**オプションを持つ新しいMODが作られます。
- 仕上げには**外に引く**など他のブラシを使い、硬いパーツには**移動**を使ってください。小さいサイズから大きいサイズへの合わせ直しが最もうまくいきます。
- **ボディMODをまたぐ場合**、2つのボディが異なる箇所では新しいボディのボーンウェイトも引き継ぎ、新しいボディの物理で動くようになります。一致する箇所では作者のウェイトをそのまま残します。スカートチェーンなど服自身のボーンは決して変更されません。
- **2つのボディの肌が同じテクスチャ配置を共有している**か、Proteusが変換できる配置（bibo、gen3、gen2）である必要があります。男性ボディと女性ボディを互いに合わせ直すことはありません。
- 肌を差し替えたときや、服が別のボディMODへ移るときは**シェイプキーが失われます**。そうなった場合はProteusが知らせます。
- **直前の結果を削除**すると、保存したサイズをMODから取り除けます。
- 合わせ直すのは最も高い詳細度（LOD）だけなので、遠く離れると元のサイズが見えることがあります。

##### 他のボディの全サイズ

1着ずつ合わせ直すツールの下にある**他のボディの全サイズ**は、MOD全体を一度に処理します。目的のボディMODにチェックを入れて**サイズを追加**を押すと、MOD内のすべての胴・脚・靴・手袋の装備が、作者の最初のサイズからそれらのボディの全サイズへ合わせ直され、「Rue S」「YAB Buff L」といった名前で作者自身のサイズの隣に保存されます。

- **YAS版があるボディはYAS版を使う**は、Rue、YAB、TreにYet Another Skeleton版のサイズを使います。すでにYASでウェイト付けされたパーツには、常にYASのサイズが作られます。
- **靴と手袋も含める**（既定でオン）は、MODの靴と手袋にもサイズを作り、元の足と手を残します。靴には脚のサイズ（「Rue WC」「YAB SC」）が、手袋にはボディごとに1つのオプションが付きます。衣装の胸や脚と同じサイズグループにある靴や手袋は、そのパーツが作ったサイズに加わるので、1つ選ぶだけで衣装全体が揃います。脚にも腕にも届かないものは、新しいボディの肌の描き方が違う場合にだけ肌を描き直します。
- MODにすでにあるサイズはそのまま残ります。Proteusが作ったサイズを作り直すには**Proteusが以前追加したサイズを作り直す**にチェックを入れてください。作者自身のサイズには決して触れません。
- 処理はバックグラウンドで行われ、大きなMODでは数分かかることがあります。**停止**しても、すでに保存したサイズは残ります。完了すると、除外せざるを得なかったものとその理由を一覧表示します。
- 選択肢に出るのはMODが対象とする種族のボディだけなので、女性用MODに男性ボディは表示されません。サイズを作るには、そのボディがPenumbraにインストールされている必要があります。ゲーム本来の装備にはサイズを追加するMODがないため、この項目は表示されません。

##### パーツのスイッチ

**パーツの切り替え**は、MODのモデルからジオメトリの一部を取り出し、オン/オフのスイッチの後ろに置きます — 作者が常時表示のメッシュに溶接してしまったリボン、首輪、ストラップなどです。

スイッチは通常のPenumbraオプションとしてMOD自体に書き込まれるため、そのMODの設定に表示されます。

モデルのパーツが三角形数とともに一覧表示されます。キャラクター上またはモデル表示でパーツをクリックすると、チェックが入ります。1つのスイッチで隠したいパーツにチェックを入れ、名前を付けて、**チェックしたパーツからスイッチを作成**を押します。好きなだけ積み上げてから、**スイッチをMODに書き込む**を押します。

知っておくとよいこと:

- **1アイテムにつきスイッチは10個まで。** これはProteusではなくゲームの制限です。作者がすでに使い切っている場合は、タブがその旨を表示し、追加できません。
- **装備とアクセサリーのみ。** 他のモデル種別にはスイッチを付ける先がありません。
- **作者がすでにスイッチを設定しているパーツにも、自分のスイッチを付けられます。** 2つは重なり、両方がオンのときだけパーツが表示されます。
- **インポートしたパックにもスイッチを付けられます。** **インポート**から取り込んだパックの服も、同じ手順でスイッチを受け取れます。
- **元に戻せます。** 元のモデルは保存されているので、**元に戻す — 元のモデルを復元**でMODは完全に元どおりになり、オプショングループも削除されます。
- 1つのアイテムにパーツの並びが異なる複数のモデルファイルがある場合、Proteusはスイッチが正しく当たるものだけを編集し、手を付けなかったものを教えてくれます。推測して間違ったジオメトリに当てることはありません。

#### 紐付け

Proteusの設定全体 — どのMODが有効か、その優先度とオプション、すべてのカラー — をGlamourerのデザインに紐付けます。**Proteusの状態をGlamourerデザインに紐付ける**は既定でオンです。

デザインを保存すると、その時点の状態が一緒に記録されます。Proteus製に限らずキャラクターに乗っているMODすべてと、Proteusのカラーすべてが対象です。あとでそのデザインを適用すると復元されます。カラーとレイヤー設定はライブのオーバーレイとして復元されるため、MOD自身のファイルが書き換えられることはありません。紐付けごとに復元するMODが一覧表示され、**適用**はGlamourerを経由せずその場で1つを復元し、**解除**はデザインに触れずにその紐付けだけを忘れます。

紐付けが有効な間、カラーエディターでの編集はすぐにプレビューされますが、紐付けタブでそのデザインの隣にある**更新**を押すまで保存されません。押すと、画面上の内容がすべてそのデザインへ書き戻されます。

| オプション | 効果 |
|--------|-------------|
| Glamourerの自動化に追従する | ギアセットやジョブの切り替えでGlamourerの自動化がデザインを適用したとき、紐付けを復元します。既定でオン。復元するだけで、消すことは決してありません。 |
| キャラクター上のすべてのMODを復元する | デザインを保存したときにキャラクターで有効だった他のMODも復元し、有効でなかったものはオフにし、デザインのMODを競合する相手より上に引き上げます。既定はオフで、そのときはProteus製MODだけが復元されます。他のMODはPenumbraの一時設定で保持するため、コレクション自体は変更されません。保持中のMODに出るPenumbraのバナーから、そのMODの保持だけを解除できます。 |
| デザインが指定しない枠を空にする | 紐付いたデザインを適用するとき、そのデザインが指定しない装備枠とメガネ枠を空にし、記録されていないインポート済みパックをオフにします。前の見た目の名残が残らないようにするためです。既定はオフ。自動化では使われず、武器とセカンドスキンを載せている枠はそのまま残ります。 |

紐付けがキャラクター全体を記録するようになる前に保存されたデザインには、**ProteusのMODのみ**と表示されます。適用してから**更新**を押すと、残りも記録されます。

#### 作成

ゲームを離れずに基本的なオーバーレイMODを作成します。名前と作者を入力し、テクスチャを最低1つ（ディフューズ、マスク、ノーマル、インデックス）選びます。マテリアル対象は現在着用中のボディから自動入力されます。ドロップダウンから別の装備中マテリアルを選ぶことも、パスを手入力することもできます。ProteusはPenumbra MODを新規作成して開きます。

選んだマテリアルが実際には使えないテクスチャスロットはグレー表示になります。

ボディの肌を対象にすると、同じテクスチャ配置を共有する他のすべての種族の同じボディも対象になるため、種族を変えてもMODが付いてきます。タブには、それが何マテリアルになるかが表示されます。女性ボディは1つの配置を、男性ボディは別の配置を共有します。ララフェルと男性ロスガルは独自の配置を持つため含まれません。

#### 取り込み

MODパックを取り込んでProteus MODに変換します。対応するのは3種類です。

**通常のPenumbra MOD（`.pmp`）** — 装備枠を使わずに通常のギアMODの一部を着用でき、さらに高度なカラーテーブル機能が加わります。 Penumbraにインストール済みのMODを変換するには、パックファイルではなくそのフォルダーの`meta.json`を選んでください。Penumbraの古い形式のパックは、まずPenumbraが更新してから変換されます。

取り込んだ後も普通のPenumbra MODのままです。オン/オフやどのオプションを選ぶかは引き続きPenumbraが管理します。変わるのは、そのパーツが実際の装備枠ではなくProteusのキャリアアイテム上に描画される点で、グラマーには影響しません。

便利な副作用として、**複数のオプションを同時に着用できます**。通常、同じグループ内の2つのオプションは同じモデルパスを取り合うため、ゲームはどちらか一方しか表示できず、「このパーツ*と*あのパーツ」という提供が物理的に不可能です。取り込み後は、選択した各パーツが個別に追加されます。

- パーツは**オフ**の状態で追加されます。あとでPenumbraで必要なものにチェックを入れてください。それまでは何も着用されません。
- *すでに*Proteus MODであるパックは、作者が作ったとおりにそのままインストールされます。変換は行われません。
- 取り込み時に肌は取り除かれます。アクセサリー、ピアス、ジャケットなどに最適です。シャツを取り込んだ場合、装備中の胴装備と同じサイズでなければ形が合いません。

**Onionのオーバーレイパック（`.omp`）** — そのレイヤーをProteusのオーバーレイとして着用し、色替えや積み替え、発光などができます。

同じ絵柄を複数のUVレイアウト（bibo、gen3、バニラ）で同梱しているパックは、Penumbra上で単一選択の**Body UV**グループになり、着用中のボディに合うレイアウトがあらかじめ選ばれます。そのため一度に合成されるのは1つだけです。レイヤーの不透明度は画像に焼き込まれます。Normal以外のブレンドモードを持つレイヤーはスキップされ、その旨が表示されます。Proteusはアルファオーバー合成しか行わないためです。Onion独自のオプショングループや種族フィルターは取り込まれません。

**Atramentum Luminisのグロータトゥー（`.ttmp2`）** — そのグローをProteusのオーバーレイとして着用し、シェーダーMODなしで色替えや減光ができます。

Atramentum Luminisのパックはグローをテクスチャのアルファチャンネルに隠しており、あのシェーダーMODが入っていないと何も描画されません。Proteusはそのグローを読み出して、通常のオーバーレイとして組み直します。作者が指定したパネルはセカンドスキンになり、絵柄そのものがアニメーショングローのマテリアルを駆動するため、ネオンはピクセルごとの色を保ちます。あとはカラーの**グロー**ダイヤルが期待どおりに働き、他のオーバーレイと同じようにデザインへ紐付けられます。

- パックが持つボディテクスチャも、独立した**作者の肌テクスチャ**オプションとして取り込まれ、既定でオンになっています。これは光らないタトゥー部分を担い、作者の肌色ではなくあなたの肌色を保ちます。グローだけが欲しい場合はPenumbraでチェックを外してください。
- Proteusはbiboとgen3をそのまま認識します。それ以外のボディでは、リサイズせずに着用中のボディへ描画し、その旨を表示します。パックが別のボディ向けなら、**ボディ**ピッカーで上書きできます。
- 種族や性別のフィルターはないため、同じマテリアルのボディなら誰にでも描画されます。対象外のキャラクターではPenumbraでオフにしてください。
- 現時点では瞳のグローは取り込まれませんが、ご希望があればお知らせください。


**プリセット（`.ptp`）** — すでに持っている Mod 用に誰かが共有した見た目。

プリセットは Mod ではないので何もインストールされません。Proteus はどの Mod 用に作られたかを読み取り、その Mod に追加するか尋ねます。その名前の Mod を持っていない場合はその旨を伝えるので、正しい Mod を自分で選んでください。保存されるだけで着用はされません。着たくなったら、その Mod のカラー内にあるプリセットセクションから着てください。
#### 書き出し

自分のProteus MODを共有用のPenumbra MODパック（`.pmp`）として保存します。ドロップダウンからMODを選び、**書き出し**を押して保存先を選ぶだけです。ファイル名はMOD名から自動で入り、ダイアログは初回はデスクトップ、以降は前回保存した場所で開きます。

パックはMODフォルダをそのままコピーしたものなので、何も失われません。オプション、カラーテーブル、マスク、グローエフェクト、ギアレイヤーがすべて付いてきて、受け取った側のProteusはPenumbraがインストールした時点で認識します。無効なMODも書き出せます。

#### 設定

| 設定 | 内容 |
|---------|-------------|
| 有効 | マスタースイッチ。オフにするとProteusの出力を消し、それなしで再描画し、Penumbra上の管理MOD「Proteus」を無効にしてデザインの紐付けも止めます。Proteusのすべての機能が退きます。 |
| 自動再描画 | Proteusが自動で追従します。エリア移動、装備変更、再描画のあとに合成し直し、続けてキャラクターを再読み込みして結果が見えるようにします。オフにするとProteusはほぼ手動になります。見た目はそのまま残りますが、編集は何かがあなたを再描画するまで表示されません。 |
| MOD優先度を自動で引き上げる | Proteusが合成先としている肌テクスチャを他のMODが上書きしていると確認された場合、ProteusのPenumbra優先度をその上に引き上げ、チャットで知らせます。 |
| その場で再読み込み | 完全な再描画の代わりに、Glamourer経由でテクスチャを更新し、消えて現れるちらつきを避けます。既定でオン。 |
| 圧縮を有効にする | 焼き込んだテクスチャをブロック圧縮し、ディスクとVRAM上のサイズを約4分の1にします。既定はオフ。Proteusの処理のなかで最も遅く、古いPCでは変更1回ごとに見た目の反映が1分以上遅れることがあります。ビデオメモリが足りないときだけオンにしてください。これに耐えられないほど遅いPCでは、チェックを入れていてもProteusはテクスチャを圧縮せず、その理由を知らせます。 |
| シャープアルファ | 実験的機能。グループポーズでスフィアマップとメタルネスを機能させ続けます。代わりに薄い生地の縁が硬くなります。 |
| テクスチャキャッシュ（MB） | 合成の間、デコード済みテクスチャをメモリにどれだけ保持するか。 |
| 重複したボディメッシュを隠す | セカンドスキンが二重に描画してしまう肌を省きます——隣のパーツがすでに覆っている関節補強リングや、領域の予備コピーなど。既定でオン、どのボディでも安全です。 |
| 透明なメガネにホストする | セカンドスキンをフェイスウェア枠に乗せ、指輪を空けておきます。 |
| 肌色の抑制 | オーバーレイが肌の色味に染まるのをどれだけ拒むか。 |
| アンビエントオクルージョン / 影の柔らかさ / Skindenting | ストラップ端の接触影とノーマルのくぼみの全体的な強さ。 |
| シーンの明るさに反応する | **明るさで薄れる**を設定したカラー行を、あなたに当たる光が強くなるほど暗くします。オフの場合、どのグローもどこでも最大の明るさで光ります。 |
| 明るさを手動で指定する / 明るさ | シーンを無視してスライダーの値を使います。夕暮れを待たずに暗所専用グローを確かめる最短の方法で、グループポーズにも適した設定です。 |
| 背景のグロー | ウィンドウの背後を漂う、やわらかな熾火の光。既定でオン。 |
| モーションを減らす | ウィンドウを静止させます。ホバー効果は即座に反映され、背景のグローと有効なMODの脈動が動かなくなります。 |

ここにある4つのボタンは覚えておく価値があります:

- **ログをコピー** — 完全な更新を一度走らせ、その間にProteusが記録した内容をすべてデスクトップのテキストファイルに保存します。Windowsのユーザー名は取り除かれます。不具合を報告するときは、そのファイルを添えてください。
- **変更されたアクセサリを元に戻す** — 無効化や入れ替えのあとにセカンドスキンが指輪やブレスレットに残ってしまった場合、完全な再描画を強制します。
- **テクスチャキャッシュを消去** — テクスチャの編集が反映されないとき（同じサイズでオーバーレイを再出力した場合など）に使います。
- **グロー用エフェクトテクスチャ** — Proteusがアニメーショングローのスクロールマップを読むフォルダを開きます。画像を入れると、すべてのギアオーバーレイのエフェクトドロップダウンに現れます。ボタンにカーソルを合わせるとフルパスが見えます。

##### 帽子

Modの髪の多くは帽子に対応しておらず、上から帽子をかぶると突き抜けてしまいます。**帽子**セクションは、帽子で隠れる部分の髪を頭に沿って押し付けます。スタジオと同じく髪MOD自身のファイルを編集するため、Proteusをオフにしても動き続け、MODを書き出せば一緒に付いていきます。

- **髪型を帽子に合わせる**は既定でオンです。Proteusは実際に帽子を被るまで待ってから、その下の髪型を合わせ、チャットで知らせます。帽子をまったく被らなければ、髪MODが触られることはありません。チェックを外すと止まり、その選択は保持されます。
- **ポニーテールを隠す**をオンにすると、帽子を被っている間、どんな帽子でも覆えない部分 — ポニーテール、サイドテール、背中に長く垂れる髪 — がさらに消えます。既定はオフです。隠す処理は全部か無かで、判定を誤った部分はそのまま消えてしまうためです。
- 着用中の髪型を自分で合わせることもできます。セクションには押し付けられる点の数とその距離が表示され、**対応させる**で変更を書き込みます。
- **元に戻す**は着用中の髪型を元に戻します。髪MODは通常、種族ごとに1つのモデルを同梱するため、**このModの髪型すべてを元に戻す**でそのMOD内でProteusが変更したすべての髪型を元に戻せます。元のファイルはMOD内の `Proteus/hatcompat-backup/` に保管されます。
- 作者がすでに帽子対応を加えている髪には手を付けず、ゲーム標準の髪は元から対応しています。例外は、帽子が覆う範囲よりはるかに多くの髪を隠す帽子対応で、たいていは元にした髪型から引き継がれたものです。Proteusはそれを再計測して置き換えることを提案します。
- **髪型に付属の帽子対応を置き換える**をオンにすると、作者が手作りした帽子対応を破棄し、Proteus自身のものを使います。手作りの対応の方がたいてい優れているため、既定はオフです。作者の版は保管され、オフに戻すと元に戻ります。
- 髪型によっては、ゲームのシェイプ形式で扱うには大きすぎるまとまりに溶接されています。そうした点は形がそのまま残るため、そこでは帽子が突き抜ける場合があります。

##### 体型の自動調整

胴・脚・手・足の装備を、身に着けた瞬間に自動であなたの体に合わせ直します。Proteusは装備がどのボディMODとサイズ向けに作られたかを割り出し、スタジオの[体型サイズ](#体型サイズ)ツールと同じ方法であなたの体に合わせ直して、新しいサイズを装備自身のMODに保存し、オンにします。開始時と完了時にはチャットで知らせます。

1. **身に着けた装備を自分の体型に自動で合わせる**にチェックを入れます。
2. **コレクション**を選びます。Penumbraのコレクションごとに個別に選択でき、初期値は今使っているコレクションです。
3. **体型**でボディMODを選び、続けて**胸のサイズ**と**脚のサイズ**を選びます。手と足はそれに合わせて自動で決まります。
4. これ以降に身に着けた装備が合わせ直されます。すでに着ている装備には**今着ている装備を調整**を押してください。

知っておくとよいこと:

- **ゲーム本来の装備も調整する**をオンにすると、バニラ装備も対象になります。保存先のMODがないため、それぞれにアイテム名とボディ名を付けた専用の新しいMODが作られ、**Proteus アップスケール**にまとめられます。
- **Penumbraでの選択が優先されます。** MODの**Original**や別のサイズを自分で選んだ場合、Proteusはそれに手を付けません。MODがすでにあなたのサイズを同梱している場合は、新しく作る代わりにそのオプションがオンになります。
- どのボディ向けのパーツか判別できない場合や、読み取れるボディの肌がパーツにない場合、Proteusはそのまま残してチャットで知らせます。その場合もスタジオで手動で合わせ直せます。
- **着ている装備の自動調整を元に戻す**（CtrlまたはShiftを押しながらクリック）は、着用中の装備に対して自動調整が作ったサイズを取り除き、バニラ装備用に作ったMODを削除し、以前のオプションに戻します。それらの装備は、**今着ている装備を調整**を押さない限り再び合わせ直されません。スタジオで自分で作ったサイズは残ります。
- **このコレクションの体型設定を消去**で、そのコレクションでの自動調整をオフにします。

### プリセット

**プリセット**とは、**ひとつの Mod** に付ける名前付きの見た目のことです。どのオプションにチェックが入っているか、すべての色、発光とレイヤーの設定を丸ごと覚えます。ボディスーツやストッキングのような手の込んだパックはグループを十数個も持っていて、見栄えのする組み合わせを見つけるにはチェックボックスをいじり回すしかありません。プリセットはその組み合わせを取っておきます。

プリセットは Mod のカラーエディタの一番下、詳細設定の下にある折りたたみ式の **プリセット** セクションにあります。**+ 保存…** で今の見た目に名前を付けて残し、隣のドロップダウンでどれを着るか選びます。折りたたんでいても、見出しが今着ているものの名前を示します。

- `*` の付いたプリセットは Mod に同梱されたものです。読み取り専用で、編集すると自分用のコピーができるため、Mod の更新であなたの保存したものが上書きされることはありません。
- 着ているプリセットの横の `●` は、保存後に何か変えたという印です。**更新**でその変更を取り込みます。放っておけばプリセットは元のままです。
- **プリセットなし**は Mod 本来の色に戻します。オプションのチェックはそのままです。見た目を外すことは、自分で切り替えた内容を取り消せという意味ではないからです。
- プリセットは気軽に試せます。Penumbra に書き込まれるのはオプションのチェックだけで、色とレイヤー設定はプリセットを着ている間だけ上に乗るため、Mod 自身のファイルには一切触れません。

**コードをコピー**（チャットに貼れる文字列）または**エクスポート…**（`.ptp` ファイル）で共有できます。受け取る側は**コードを貼り付け**または**インポート…**を使います。別の Mod 用のプリセットは、追加する前にその旨を知らせます。

デザインバインドが有効なときにプリセットを適用すると、ほかの編集と同じくそのバインドへのプレビューになります。残すには紐付けタブで**更新**を押してください。Glamourer のデザインを適用すると、デザインが自前の色を持っているためプリセットは外れます。プリセット自体は保存されたままです。

Mod の更新でオプションの名前が変わったり無くなったりした場合、古いプリセットを適用すると残っているものはすべて設定され、できなかった分を知らせます。

### カラーエディター

MODの隣の**カラー**をクリックすると、そのMODのカラーエディターが専用ウィンドウで開きます。ここでオーバーレイの色付け、グローの制御、領域ごとのマテリアル設定を、ファイルを一切編集せずに行えます。

有効なオーバーレイオプションごとに、上部へタブが1つずつ、重なり順に並びます。タブをドラッグすると積み替えられます。MODがマスクを使っている場合は、**マスク**タブが先頭に固定されます。マスクは常に他のすべての上に描画されます。

#### 描画モード

Proteusは実際に使われている機能から各オーバーレイの描画方法を判断し、その結果を**描画モード**バッジとして表示します:

- **Skin（塗り）** — 肌に合成されます。既定値。
- **Cloth** — スフィアマップ、メタルネス、スペキュラを使うセカンドスキン。
- **アニメーショングロー** — スクロールするグローエフェクトを持つセカンドスキン。

自分で選ぶ必要はありません。スフィアマップを設定すれば、それだけでClothになります。強制したい場合は**詳細設定**を開いてモードを固定してください。そこにある**既定値に戻す**で、MODが指定した設定に戻ります。

#### 詳細設定

行の下にある**詳細設定**には、1行ではなくMOD全体に適用される設定が入っています:

| 設定 | 内容 |
|---------|-------------|
| 描画モードを固定 | 機能から自動判定させる代わりに、Skin / Cloth / アニメーショングローを固定します。**自動に戻す**で解除します。 |
| gen2/バニラにも重ねる | 着用中のバニラ（gen2）の肌にもこのMODを塗ります。多くは装備に付属する肌です。既定でオンで、バニラの肌が乗っていないときは負荷がありません。biboとgen3/Eveには常に塗られます。MOD全体に適用され、グローバル設定です。デザインの紐付けはこれを記録しません。 |
| 既定値に戻す | このオプションのカラー、グロー、モードを、ProteusがそのMODについて最初に記録した設定へ戻します。Ctrlを押しながらで実行できるようになります。 |

MODに有効なオプションがない場合、表示するカラーはありませんが、**gen2/バニラにも重ねる**に手が届くよう**詳細設定**だけは表示されます。

#### エフェクトとジオメトリ

さらに2つの折りたたみ項目がMOD全体に適用されます。

- **エフェクト**には、アニメーショングローのエフェクト選択と、ストラップ端の接触影とノーマルのくぼみである**Skindent**が入っています。Skindentはパックが要求しない限りオフです。覆われた部分を肌に押し当てられた布として扱うため、タトゥーには適さないからです。**パック**はMODが指定した設定に従い、**オン**と**オフ**はそれを上書きします。
- **ジオメトリ**は、Proteusがあなたの体から作る服の形を整え、塗りではなく布として見えるようにします。Proteusはセカンドスキンを体の複製として作るため、既定ではくぼみをすべてなぞります。
  - **胸の谷間を渡す**: 胸の間の布が、本物の布のようにまっすぐ渡ります。内側へ引き込むことはないので、体に食い込むことはありません。
  - **臀部の間を渡す**: 座面でも同じように渡します。
  - **股間をなめらかにする**: 股のしわをなめらかにします。下にある体そのものを変えるため、そのとき着ているすべての服に適用されます。
  - **乳首をなめらかにする**: その上の布をなめらかにします。まだ未完成です。下の体は形を保つため、体に沿う服ではなお浮き出ることがあります。

  いずれかをオンにすると、そのMODはセカンドスキンとして描画されます。

#### オーバーレイのオプション

行の下に、オーバーレイのタブでは次の項目が出ることがあります。

- **このオーバーレイが肌そのもの** — 変換した肌MOD向けの項目で、肌の上に載せる何かではなく肌そのものであるアートを指します。ノーマルマップが肌のものに加算されるのではなく置き換え、肌色の抑制が0まで下がって自分の肌色が出ます。
- **このアートは左右非対称** — 左右が異なるべきときにオンにします。片腕だけのタトゥーや、左右対称でないメイクなどです。バニラのボディと顔はアートを半分に折って使うため、オンにしないと片側がもう片側へミラーリングされます。Proteusが自動で判別することはできません。
- **つま先補強** — つま先が補強されたストッキングで、より密なつま先を編みます。つま先が透けたまま暗くなるパネルが、縁に向かって薄れていきます。**密度**でどれだけ詰まって見えるかを決めます。MODに保存されるため、プリセットやデザインはこれを記録しません。

#### 行

エディターは最大16のカラーテーブル行を表示します。行は、MODのインデックステクスチャ（あれば）が定義する領域に対応します。行16は、インデックステクスチャがない場合に使われるフォールバックの色です。インデックステクスチャが一度も選ばない行は淡く表示されます。

任意のサブ行で**光らせる**を押すと、キャラクター上でその領域が発光するので、どの行が何を制御しているか分かります。

各行には2つのサブ行があります:
- **A** — インデックステクスチャのグリーンチャンネルが255の箇所に適用されます。
- **B** — グリーンチャンネルが0の箇所に適用されます。中間の値はなめらかに混ざります。

各サブ行について:
- **ディフューズ**（カラースウォッチ） — オーバーレイに乗算で掛かる色味。白（`#FFFFFF`）はオーバーレイ本来の色を表示します。それ以外の色は色味を付けます。ここで色を選べば、無地のグレースケールのストッキングも色替えできます。
- **グロー**（0〜1スライダー） — オーバーレイがどれだけ強く光るか。専用の色を持ちます。肌は発光できないため、ここを設定するとスフィアマップと同様、オーバーレイはクロスレイヤーに切り替わります。
- **不透明度**（-100〜100スライダー） — 0がMODの既定値。-100で透明、100で完全に不透明になります。
- **スフィアマップ / メタルネス / ラフネス / スペキュラ** — Clothで使えます。どれか1つでも設定すると、オーバーレイはセカンドスキンに切り替わります。

行とサブ行は互いにコピー＆貼り付けできます。

変更は画面上で即座に反映され、編集の手を止めてから1秒ほどで再合成されます。変更はMODの`metadata.json`に保存されます — ただしデザインの紐付けが有効な場合は、紐付けタブで**更新**を押すまでそのデザインに属します。
